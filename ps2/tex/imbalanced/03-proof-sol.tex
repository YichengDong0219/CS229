\begin{answer}
    \subsection*{Given:}
\begin{enumerate}
    \item $p < 0.5$ $\rightarrow$ The minority class occurs with p \\
    The majority class occurs with (1-p)
    
    \item $K = \frac{p}{1-p} \rightarrow$ The ratio between p \& (1-p)
\end{enumerate}

Prove $\bar{A_D} = A_D$:
\[ A_D = \frac{1}{2}(A_0 + A_1) \]

The new dataset D' has as many negative examples $N_0$ as D but a new amount of positive examples $N_1' = N_1 \cdot \frac{1}{K}$

The accuracy of D' is as following:
\[ A_D' = \frac{TP+TN}{TP+FN+TN+FP} \]

\begin{enumerate}
    \item By definition, follows: $TP' = A_1(TP'+FN') = A_1 N_1'$ \\
    $TN' = A_0(TN'+FP') = A_0 N_0$
\end{enumerate}

We get: $A_D' = \frac{A_1 N_1' + A_0 N_0}{N_1' + N_0}$

With $k = \frac{p}{1-p} \rightarrow \frac{N_1}{N_0}$, we can derive $N_1=N_0 K$. With this we get $N_1' = N_0 k \frac{1}{k}$. \\

Inserting this into 3)
\begin{align*}
    3) \quad A_D' &= \frac{A_1 N_0 + K A_0 N_0}{N_0 + K N_0} = \frac{A_1+A_0}{2} = \frac{1}{2}(A_1+A_0)
\end{align*}

\subsection*{Weighted loss function:}
As in D' every positive example occurs $\frac{1}{K}$ as often, we need to weigh the training examples accordingly. 

So, we can express define a weight $w^{(i)} = \begin{cases} 1 & \text{if } y^{(i)}=0 \\ \frac{1}{K} & \text{if } y^{(i)}=1 \end{cases}$ so that our data gets weighted accordingly.

With a total of $N' = N_0 + N_1' = 2N_0$, we can say:
\[ J(\theta) = -\frac{1}{N'} \sum_{i=1}^{N'} w^{(i)} \left(y^{(i)}\log(h_{\theta}(x^{(i)}))
+  (1 - y^{(i)})\log(1 - h_{\theta}(x^{(i)}))\right) \]
With $N_0=\frac{n}{(1+k)}$ we can say, $N'=\frac{2n}{(1+k)}$
\[ J'(\theta) = -\frac{1 + k}{2n} \sum_{i=1}^{2N_0} w^{(i)} \left(y^{(i)}\log(h_{\theta}(x^{(i)}))
+  (1 - y^{(i)})\log(1 - h_{\theta}(x^{(i)}))\right)\]

\end{answer}
