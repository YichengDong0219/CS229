\begin{answer}
    Using only linear functions as activation functions will not work. Even if the output activation function is a step function, we need to distinguish which side of each specific (linear) decision boundary---drawn by $h_1$, $h_2$, and $h_3$---the input lies on. However, in the output $o$, all these boundaries collapse into a single linear calculation, making it impossible to differentiate between the sides.

\end{answer}
