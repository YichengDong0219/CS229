\begin{answer}
    1) Similar to 1b), we are now trying to find a case where the misclassification loss equals the weighted average of the children's misclassification loss.

    $$M(R_p) = \frac{|R_1|M(R_1) + |R_2|M(R_2)}{|R_p|}$$

    Let $N_m = |R_m|$ be the number of examples in a region $m$, and $N_{mk}$ be the count of class $k$ examples in that region.

    The misclassification loss for a region $m$ is defined as:

    $$M(R_m) = 1 - \max_k \frac{N_{mk}}{N_m} = \frac{N_m - \max_k N_{mk}}{N_m}$$

    2) This equation also tells us basically that the total number of misclassified points in the parent is equal to the sum of misclassified points in the children:

    $$N_p - \max_k N_{pk} = (N_1 - \max_k N_{1k}) + (N_2 - \max_k N_{2k})$$

    The total number of misclassified points in $R_m$, are hence $N_m - \max_k N_{mk}$.

    With the cases in 1b) still holding true, we can also get an equal split if the split is somehow meaningful and changes the mix of examples in each node ($p_1 \neq p_2$) but the majority class would stay the same. 

    3) Proof of equal loss

    Let $k^* = \arg\max_k N_{pk} = \arg\max_k N_{1k} = \arg\max_k N_{2k}$.

    With the majority class $k^*$, and the equation in Step 2), we get:

    $$N_p - N_{p,k^*} \stackrel{?}{=} (N_1 - N_{1,k^*}) + (N_2 - N_{2,k^*})$$

    The right hand side equals:
    $$(N_1 - N_{1,k^*}) + (N_2 - N_{2,k^*}) = (N_1 + N_2) - (N_{1,k^*} + N_{2,k^*}) = N_p - N_{p,k^*}$$

    This is, because we know, that the total points are always $N_p = N_1 + N_2$, and the points in a specific class equals the points in each node of that class. The equality holds.
\end{answer}
