\begin{answer}
    
    Let $T_i$ be a tree for all $i \in \{1,\ldots,B\}$, and $T_j$ another tree for $j \neq i$.

    Let $\hat{T}$ be the average prediction: $\hat{T} = \frac{1}{B} \sum_{i=1}^B T_i$. 

    We can assume the variance of each tree is the same, so: $\text{Var}(T_i) = \sigma^2$.

    1) Let the correlation between $T_i$ and $T_j$ be:

    $$\text{Cov}(T_i, T_j) = \text{Corr}(T_i, T_j) \sqrt{\text{Var}(T_i)\text{Var}(T_j)} = \rho \sqrt{\sigma^2 \sigma^2} = \rho\sigma^2$$

    2) The general formula for the variance of a sum of $B$ random variables is, in our case $T_i$ for all $i \in \{1,\ldots,B\}$:

    $$\text{Var}\left(\sum_{i=1}^B T_i\right) = \sum_{i=1}^B \text{Var}(T_i) + \sum_{i \neq j} \text{Cov}(T_i, T_j)$$

    3) Now we can combine both:

    First, we have $B$ terms in the first sum of the variance, as we have B variances, and then for the covariances, we have $B \cdot (B-1)$ pairs of $(i,j)$ where $i \neq j$. So we get:

    $$\text{Var}\left(\sum_{i=1}^B T_i\right) = B\sigma^2 + B(B-1)\rho\sigma^2$$

    4) With this, we can now find the variance of $\hat{T}$. We can use the general property that $\text{Var}(cX) = c^2\text{Var}(X)$, where $c = \frac{1}{B}$:

    $$\text{Var}(\hat{T}) = \text{Var}\left(\frac{1}{B}\sum_{i=1}^B T_i\right) = \frac{1}{B^2} \text{Var}\left(\sum_{i=1}^B T_i\right)$$

    $$\Leftrightarrow \text{Var}(\hat{T}) = \frac{1}{B^2} \left( B\sigma^2 + B(B-1)\rho\sigma^2 \right)$$

    Simplifying further:

    $$\text{Var}(\hat{T}) = \frac{B\sigma^2}{B^2} + \frac{B(B-1)\rho\sigma^2}{B^2} = \frac{\sigma^2}{B} + \frac{(B-1)\rho\sigma^2}{B} = \frac{\sigma^2}{B} + \rho\sigma^2 - \frac{\rho\sigma^2}{B} = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$

    Q.E.D.
\end{answer}
